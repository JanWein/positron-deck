# Elgato review demo

Record approximately 60 seconds on Windows. Keep the laptop screen and physical Stream Deck in the same shot. Use a small disposable R or Python project with the matching IDE extension installed. Do not show credentials, customer data or private repository content.

## Spoken script (English, about 110 words)

“Hi, I'm Jan, the developer of Positron Deck.

The plugin provides fourteen configurable actions. Here, I drag Code onto a button and choose Run Selection in the property inspector. The button's title and icon update automatically.

With Positron focused, I press the button and the selected code runs in the console.

Next, I use Navigation to open Data Connections, and Layout to change the workspace arrangement.

Language Tools offers R and Python options, while Quarto has its own render and preview functions.

The plugin sends local keyboard shortcuts and also works with a focused remote Workbench session.

This is the revised plugin submitted for Marketplace review. Thank you.”

## Recording sequence

| Time | Show |
|---|---|
| 0–8 seconds | Positron and Stream Deck; introduce the plugin. |
| 8–22 seconds | Stream Deck app: drag Code to a button, choose Run Selection; show title/icon updating. |
| 22–35 seconds | Focus Positron, select a harmless R/Python expression, press the physical button; show console output. |
| 35–47 seconds | Press preconfigured Navigation and Layout buttons; show visible changes in Positron. |
| 47–57 seconds | Stream Deck app: show Language Tools > Python and the Quarto function menu. |
| 57–65 seconds | Return to Positron and close. |

Prepare Navigation > Data Connections and Layout > a visibly different layout before recording. If Data Connections is unavailable in your installation, use Explorer and change the spoken line accordingly. The language selector filters the tool menu; it does not switch Positron runtimes. Only mention a remote Workbench session as demonstrated if you actually show one; otherwise the script states capability, not a live remote test.

Send the video to maker@elgato.com and reference the existing Positron Deck submission. This repository does not contain a fabricated functionality recording.
